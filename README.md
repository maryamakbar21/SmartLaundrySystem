# SmartLaundrySystem

## 📌 Project Overview

SmartLaundrySystem is a SQL Server database project designed for a real-world laundry management business.

The project manages customers, orders, services, workers, payments, delivery tracking, employee attendance, feedback, and promotional coupons through a relational database.

## 🗄️ Database Structure

The database includes the following tables:

- Customers
- Orders
- Order_Items
- Workers
- Services
- Payments
- Delivery_Tracking
- Employee_Attendance
- Feedback
- Coupons
- Customer_Coupons

The database uses primary keys and foreign keys to maintain relationships and data integrity between tables.
